# CARSOL Meta Ads

このフォルダをCARSOLのMeta広告運用に関する正本（Source of Truth）とする。

Movance等の別事業でMeta広告制作・分析の知見が必要な場合は、このCARSOL側のマニュアルとLearning Logを参照する。CARSOL固有の事実・広告成果・顧客インサイトをMovance側へ複製して正本化しない。

## 構成

- `META_AD_CREATIVE_AND_OPERATIONS_MANUAL.md` — クリエイティブ制作・入稿・配信・分析の共通実務ルール
- `AUTOMATION_WORKFLOW_GPT_TO_CLAUDE_CODE.md` — GPT制作からClaude Code下書き保存までのワークフロー
- `CARSOL_META_AD_PLAYBOOK.md` — CARSOL固有の事実、訴求、運用ルール、仮説
- `CARSOL_META_AD_LEARNING_LOG.md` — 広告実績、勝ち筋・負け筋、顧客インサイト、記事化候補

## 運用原則

1. CARSOL広告を作る前にPlaybookとLearning Logを読む。
2. GPTは事実条件を勝手に補完しない。
3. Claude Codeは下書き保存まで。広告公開は人が最終確認する。
4. 広告結果はCPAだけでなく、電話→有効相談→査定→成約→粗利益まで記録する。
5. 顧客の実際の質問・困りごとは記事・SEO・LP改善へ再利用する。
